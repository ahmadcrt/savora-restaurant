# Savora Restaurant

A **fictional** premium restaurant website built as a web development portfolio piece. Savora does not exist: the address, phone, email, WhatsApp number, prices and testimonials are placeholders, and the reservation form is a front-end demo that sends nothing.

## Technologies
HTML5 · CSS3 (custom properties, grid, flexbox) · Vanilla JavaScript. No frameworks or libraries.

## Features
- Responsive layout with an accessible mobile menu
- Hero, story, signature menu with working category filters, chef's specials
- Gallery with lightbox (Esc, arrow keys, focus return)
- Reservation form with inline validation and a clearly labelled demo confirmation
- Smooth scrolling, reduced-motion support, visible focus states
- Branded placeholder replaces any photo that fails to load

## Structure
`index.html` · `css/style.css` · `js/script.js` · `assets/images/`

Photos load from Unsplash. To work offline, save images into `assets/images/` and edit the `url()` helper in `js/script.js`.

## Limitations
No backend, no real bookings. Photo availability depends on Unsplash.
